2. Revise os dados extraídos 0 ofertas

Como funciona

As imagens são enviadas à API do Gemini pelo servidor Supabase. Após a análise, os dados aparecem para revisão. Só o botão “Confirmar e gravar no GitHub” tenta atualizar precos-registrados.json; as ofertas existentes são preservadas e duplicatas são ignoradas.

A integração depende de três segredos configurados no Supabase: GEMINI_API_KEY, GITHUB_TOKEN e ENCARTES_TEST_KEY. Se ainda não estiverem configurados, a página mostrará um erro claro.
